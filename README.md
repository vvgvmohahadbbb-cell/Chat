# 👨‍👩‍👧‍👦 خريطة العائلة (Family Map)

تطبيق أندرويد لمشاركة المواقع بشكل **شفاف ومتبادل** بين أفراد العائلة: كل واحد شايف الكل على خريطة حية، وكل واحد يتحكم بمشاركة موقعه هو بس (تشغيل/إيقاف من جهازه). فيه كمان دردشة جماعية، محادثات خاصة بين شخصين، إرسال صور، وتشفير للرسائل.

⚠️ هاد تطبيق شخصي (side-load)، مش من متجر Google Play.

---

## ⚠️ خطوات إلزامية قبل أول بناء (بدونها البناء رح يفشل)

### 1) أنشئ مشروع Firebase
1. روح لـ 🔗 https://console.firebase.google.com
2. **Add project** → اختار اسم (مثلاً FamilyMap) → أكمل الإنشاء
3. جوا المشروع، اضغط أيقونة أندرويد ➕ لإضافة تطبيق أندرويد:
   - **Android package name:** `com.ishhf.familymap` (لازم يطابق بالضبط)
   - نزّل ملف **google-services.json**
4. **حط ملف google-services.json جوا مجلد `app/`** بمشروعك (نفس مستوى ملف `app/build.gradle`)

### 2) فعّل تسجيل الدخول المجهول (Anonymous)
Firebase Console → **Authentication** → **Sign-in method** → فعّل **Anonymous**

(التطبيق بيستخدم هالنوع بالخلفية بس عشان يحقق شرط الأمان بقاعدة البيانات — تسجيل الدخول يلي بيشوفه المستخدم هو بس اسم وكلمة سر عاديين.)

### 3) فعّل Firestore Database
Firebase Console → **Firestore Database** → **Create database** → اختار أي موقع سيرفر قريب → ابدأ بوضع **test mode** مؤقتاً

بعدها روح لتبويب **Rules** والصق هاد بدل المحتوى الافتراضي:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
اضغط **Publish**.

### 4) فعّل Storage (لحفظ الصور)
Firebase Console → **Storage** → **Get started** → اتبع الخطوات الافتراضية

بعدها تبويب **Rules** بالـ Storage، والصق:
```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
اضغط **Publish**.

### 5) احصل على مفتاح Google Maps
1. روح لـ 🔗 https://console.cloud.google.com/google/maps-apis/credentials (بنفس حساب Google يلي عملت فيه Firebase)
2. فعّل **Maps SDK for Android** من مكتبة الـ APIs
3. اعمل API Key جديد
4. افتح ملف `app/src/main/AndroidManifest.xml` وبدّل السطر:
   ```
   android:value="ضع_مفتاح_خرائط_جوجل_هون"
   ```
   بمفتاحك الحقيقي.

## 👑 تفعيل حساب محمد كصاحب التطبيق

الاسم نفسه هو الهوية (بدل UID معقد)، فالخطوات بسيطة:

1. تأكد إنه بملف `app/src/main/java/com/ishhf/familymap/Constants.kt` مكتوب بالضبط:
   ```kotlin
   const val OWNER_USERNAME = "محمد"
   ```
2. من التطبيق، اضغط **"إنشاء حساب جديد"**، واكتب الاسم **بالضبط** `محمد` (نفس الكتابة تماماً)، وكلمة السر يلي بدك ياها (مثلاً `123410`)
3. خلص — أول ما يسجل، تلقائياً رح يبين بتاج 👑 جنب اسمه بالدردشة وقائمة الأعضاء، وعنده وحده زر **"مسح الكل"** بالدردشة الجماعية ما بيبين لغيره.

⚠️ لو غيّرت الاسم بـ Constants.kt لازم يطابق **بالضبط** (حرف بحرف) الاسم يلي هيسجل فيه محمد، وإلا الميزات الخاصة ما رح تشتغل.

## 🔐 عن التشفير

الرسائل متشفرة بـ AES-256/GCM قبل ما تترفع لـ Firestore، ومفكوكة بس وقت العرض بالتطبيق. هاد بيحميها لو حدا وصل مباشرة لقاعدة البيانات بدون علمكم — بس المفتاح نفسه محفوظ جوا كود التطبيق (مو تشفير طرف-لطرف كامل زي واتساب).

---

## 📲 طريقة الاستخدام

1. كل فرد بالعائلة ينزّل نفس الـ APK وينشئ حساب (أو يسجل دخول لو عنده أصلاً)
2. من شاشة الخريطة: مفتاح **"مشاركة موقعي"** يشغّل/يوقف مشاركة موقعك أنت بس
3. زر 👥 يفتح قائمة الأعضاء — اضغط على أي اسم لفتح محادثة خاصة معه
4. زر 💬 يفتح الدردشة الجماعية
5. 📷 بالدردشة لإرسال صورة

---

## ❌ غير مشمول حالياً: المكالمات الصوتية

بناء مكالمات صوتية حقيقية بحاجة WebRTC + سيرفر signaling، وهاد مشروع تقني منفصل. لو حابب تضيفها لاحقاً، أفضل طريقة عملية هي دمج مكتبة جاهزة زي **ZegoCloud** أو **Agora** (عندهم SDK أندرويد جاهز وباقة مجانية) بدل بناء الحل من الصفر.
